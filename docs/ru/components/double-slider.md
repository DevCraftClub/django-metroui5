# Double Slider

На странице появляется поле.

## Вызов

```python
from metroui5.components import render_double_slider

render_double_slider()
```

Пустое или неверное значение: `render_double_slider()` даёт `<input data-role="double-slider"></input>`.

В шаблоне:

```django
{% metroui5_double_slider %}
```
