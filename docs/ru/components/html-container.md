# Html Container

Компонент Metro html-container.

## Вызов

```python
from metroui5.components import render_html_container

render_html_container()
```

Пустое или неверное значение: `render_html_container()` даёт `<div data-role="html-container"></div>`.

В шаблоне:

```django
{% metroui5_html_container %}
```
