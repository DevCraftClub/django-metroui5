# Sidenav Simple

Компонент Metro sidenav-simple.

## Вызов

```python
from metroui5.components import render_sidenav_simple

render_sidenav_simple()
```

Пустое или неверное значение: `render_sidenav_simple()` даёт `<ul data-role="sidenav-simple"></ul>`.

В шаблоне:

```django
{% metroui5_sidenav_simple %}
```
