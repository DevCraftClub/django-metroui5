# Toggle Button

Компонент Metro toggle-button.

## Вызов

```python
from metroui5.components import render_toggle_button

render_toggle_button()
```

Пустое или неверное значение: `render_toggle_button()` даёт `<div data-role="toggle-button"></div>`.

В шаблоне:

```django
{% metroui5_toggle_button %}
```
