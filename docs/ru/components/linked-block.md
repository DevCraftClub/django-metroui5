# Linked Block

Компонент Metro linked-block.

## Вызов

```python
from metroui5.components import render_linked_block

render_linked_block()
```

Пустое или неверное значение: `render_linked_block()` даёт `<div data-role="linked-block"></div>`.

В шаблоне:

```django
{% metroui5_linked_block %}
```
