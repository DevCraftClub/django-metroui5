# Resizable Container

Компонент Metro resizable-container.

## Вызов

```python
from metroui5.components import render_resizable_container

render_resizable_container()
```

Пустое или неверное значение: `render_resizable_container()` даёт `<div data-role="resizable-container"></div>`.

В шаблоне:

```django
{% metroui5_resizable_container %}
```
