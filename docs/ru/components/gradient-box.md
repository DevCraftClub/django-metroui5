# Gradient Box

Компонент Metro gradient-box.

## Вызов

```python
from metroui5.components import render_gradient_box

render_gradient_box()
```

Пустое или неверное значение: `render_gradient_box()` даёт `<div data-role="gradient-box"></div>`.

В шаблоне:

```django
{% metroui5_gradient_box %}
```
