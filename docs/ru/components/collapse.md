# Collapse

На странице появляется блок из примера.

## Вызов

```python
from metroui5.components import render_collapse

render_collapse()
```

Пустое или неверное значение: `render_collapse()` даёт `<div class="" id="collapse-component" data-role="collapse"></div>`.

В шаблоне:

```django
{% metroui5_collapse %}
```
