# Bottom Sheet

Нижняя панель из примера Metro.

## Вызов

```python
from metroui5.components import render_bottom_sheet

render_bottom_sheet()
```

Пустое или неверное значение: `render_bottom_sheet()` даёт `<ul data-role="bottomsheet" class="bottom-sheet"></ul>`.

В шаблоне:

```django
{% metroui5_bottom_sheet %}
```
