# Wizard Classic

Компонент Metro wizard-classic.

## Вызов

```python
from metroui5.components import render_wizard_classic

render_wizard_classic()
```

Пустое или неверное значение: `render_wizard_classic()` даёт `<div data-role="wizard-classic"></div>`.

В шаблоне:

```django
{% metroui5_wizard_classic %}
```
