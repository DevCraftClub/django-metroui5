# Cookie Disclaimer

Компонент Metro cookie-disclaimer.

## Вызов

```python
from metroui5.components import render_cookie_disclaimer

render_cookie_disclaimer()
```

Пустое или неверное значение: `render_cookie_disclaimer()` даёт `<div class="cookie-disclaimer"></div>`.

В шаблоне:

```django
{% metroui5_cookie_disclaimer %}
```
