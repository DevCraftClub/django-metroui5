# Image Placeholder

Компонент Metro image-placeholder.

## Вызов

```python
from metroui5.components import render_image_placeholder

render_image_placeholder()
```

Пустое или неверное значение: `render_image_placeholder()` даёт `<img data-role="image-placeholder">`.

В шаблоне:

```django
{% metroui5_image_placeholder %}
```
