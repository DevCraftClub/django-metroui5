# Container

На странице появляется блок из примера.

## Вызов

```python
from metroui5.components import render_container

render_container()
```

Пустое или неверное значение: `render_container()` даёт `<div class="container" id="container-component"></div>`.

В шаблоне:

```django
{% metroui5_container %}
```
