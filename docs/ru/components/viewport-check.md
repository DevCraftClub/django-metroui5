# Viewport Check

Компонент Metro viewport-check.

## Вызов

```python
from metroui5.components import render_viewport_check

render_viewport_check()
```

Пустое или неверное значение: `render_viewport_check()` даёт `<div data-role="viewport-check"></div>`.

В шаблоне:

```django
{% metroui5_viewport_check %}
```
