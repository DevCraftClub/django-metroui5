# Image Grid

Компонент Metro image-grid.

## Вызов

```python
from metroui5.components import render_image_grid

render_image_grid()
```

Пустое или неверное значение: `render_image_grid()` даёт `<div data-role="image-grid" class="image-grid"></div>`.

В шаблоне:

```django
{% metroui5_image_grid %}
```
