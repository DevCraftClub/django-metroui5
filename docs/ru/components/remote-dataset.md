# Remote Dataset

Компонент Metro remote-dataset.

## Вызов

```python
from metroui5.components import render_remote_dataset

render_remote_dataset()
```

Пустое или неверное значение: `render_remote_dataset()` даёт `<div data-role="remote-dataset"></div>`.

В шаблоне:

```django
{% metroui5_remote_dataset %}
```
