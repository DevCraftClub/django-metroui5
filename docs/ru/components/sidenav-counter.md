# Sidenav Counter

Компонент Metro sidenav-counter.

## Вызов

```python
from metroui5.components import render_sidenav_counter

render_sidenav_counter()
```

Пустое или неверное значение: `render_sidenav_counter()` даёт `<ul data-role="sidenav-counter"></ul>`.

В шаблоне:

```django
{% metroui5_sidenav_counter %}
```
