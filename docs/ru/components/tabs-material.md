# Tabs Material

Компонент Metro tabs-material.

## Вызов

```python
from metroui5.components import render_tabs_material

render_tabs_material()
```

Пустое или неверное значение: `render_tabs_material()` даёт `<ul data-role="materialtabs"></ul>`.

В шаблоне:

```django
{% metroui5_tabs_material %}
```
