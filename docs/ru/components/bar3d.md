# Bar3D

На странице появляется блок из примера.

## Вызов

```python
from metroui5.components import render_bar3d

render_bar3d()
```

Пустое или неверное значение: `render_bar3d()` даёт `<div class="bar3d" data-role="bar3d" id="bar3d-component"></div>`.

В шаблоне:

```django
{% metroui5_bar3d %}
```
