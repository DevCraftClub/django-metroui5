# Image Carousel

Компонент Metro image-carousel.

## Вызов

```python
from metroui5.components import render_image_carousel

render_image_carousel()
```

Пустое или неверное значение: `render_image_carousel()` даёт `<div data-role="image-carousel"></div>`.

В шаблоне:

```django
{% metroui5_image_carousel %}
```
