# Transform Button

Компонент Metro transform-button.

## Вызов

```python
from metroui5.components import render_transform_button

render_transform_button()
```

Пустое или неверное значение: `render_transform_button()` даёт `<button class="transform-button"></button>`.

В шаблоне:

```django
{% metroui5_transform_button %}
```
