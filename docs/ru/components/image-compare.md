# Image Compare

Компонент Metro image-compare.

## Вызов

```python
from metroui5.components import render_image_compare

render_image_compare()
```

Пустое или неверное значение: `render_image_compare()` даёт `<div data-role="image-compare" class="image-compare"></div>`.

В шаблоне:

```django
{% metroui5_image_compare %}
```
