# Image Button

Компонент Metro image-button.

## Вызов

```python
from metroui5.components import render_image_button

render_image_button()
```

Пустое или неверное значение: `render_image_button()` даёт `<button class="image-button"></button>`.

В шаблоне:

```django
{% metroui5_image_button %}
```
