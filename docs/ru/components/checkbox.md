# Checkbox

На странице появляется поле.

## Вызов

```python
from metroui5.components import render_checkbox

render_checkbox()
```

Пустое или неверное значение: `render_checkbox()` даёт `<input class="" id="checkbox-component" type="checkbox" data-role="checkbox">`.

В шаблоне:

```django
{% metroui5_checkbox %}
```
