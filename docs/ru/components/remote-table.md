# Remote Table

Компонент Metro remote-table.

## Вызов

```python
from metroui5.components import render_remote_table

render_remote_table()
```

Пустое или неверное значение: `render_remote_table()` даёт `<div data-role="remote-table"></div>`.

В шаблоне:

```django
{% metroui5_remote_table %}
```
