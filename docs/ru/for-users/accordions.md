# Аккордеон

Список заголовков. Нажатие открывает текст под заголовком.

В шаблоне страницы, после `{% load metroui5 %}`:

```django
{% metroui5_accordion items %}
```

`items` — список, который вы уже передали в страницу. Если список пуст, на странице остаётся пустая рамка аккордеона, без текста внутри.
