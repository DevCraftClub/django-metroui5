# Chart Card

MetroUI Chart Card Component

## Call

```python
from metroui5.components import render_chart_card

render_chart_card()
```

Empty or invalid: `render_chart_card()` returns `<div class="chart-card" id="chart_card-component"><div class="content"></div><div class="chart"></div></div>`.

In a template:

```django
{% metroui5_chart_card %}
```
