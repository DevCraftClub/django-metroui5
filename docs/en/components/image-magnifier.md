# Image Magnifier

Компонент Metro image-magnifier.

## Call

```python
from metroui5.components import render_image_magnifier

render_image_magnifier()
```

Empty or invalid: `render_image_magnifier()` returns `<div data-role="image-magnifier"></div>`.

In a template:

```django
{% metroui5_image_magnifier %}
```
