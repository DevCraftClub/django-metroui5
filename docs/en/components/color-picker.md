# Color Picker

MetroUI Color Picker Component

## Call

```python
from metroui5.components import render_color_picker

render_color_picker()
```

Empty or invalid: `render_color_picker()` returns `<input class="" type="text" data-role="color-picker" id="color-picker-component"></input>`.

In a template:

```django
{% metroui5_color_picker %}
```
