# Date Picker

MetroUI Date Picker Component

## Call

```python
from metroui5.components import render_date_picker

render_date_picker()
```

Empty or invalid: `render_date_picker()` returns `<input class="date-picker" type="text" data-role="date-picker">`.

In a template:

```django
{% metroui5_date_picker %}
```
