# Color Selector

MetroUI Color Selector Component

## Call

```python
from metroui5.components import render_color_selector

render_color_selector()
```

Empty or invalid: `render_color_selector()` returns `<div class="" id="color-selector-component" data-role="color-selector"></div>`.

In a template:

```django
{% metroui5_color_selector %}
```
