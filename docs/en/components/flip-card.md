# Flip Card

MetroUI Flip Card Component

## Call

```python
from metroui5.components import render_flip_card

render_flip_card()
```

Empty or invalid: `render_flip_card()` returns `<div class="flip-card" data-role="flip-card"><div class="front"></div><div class="back"></div></div>`.

In a template:

```django
{% metroui5_flip_card %}
```
