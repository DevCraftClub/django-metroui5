# Command Button

MetroUI Command Button Component

## Call

```python
from metroui5.components import render_command_button

render_command_button()
```

Empty or invalid: `render_command_button()` returns `<button class="command-button" id="command-button-component" type="button"></button>`.

In a template:

```django
{% metroui5_command_button %}
```
