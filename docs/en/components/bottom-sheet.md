# Bottom Sheet

Нижняя панель из примера Metro.

## Call

```python
from metroui5.components import render_bottom_sheet

render_bottom_sheet()
```

Empty or invalid: `render_bottom_sheet()` returns `<ul data-role="bottomsheet" class="bottom-sheet"></ul>`.

In a template:

```django
{% metroui5_bottom_sheet %}
```
