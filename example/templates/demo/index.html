Установка и настройка

MetroUI5 легко интегрируется с вашими Django проектами:

  1. Установите пакет: pip install django-metroui5
  2. Добавьте в INSTALLED_APPS: 'metroui5'
  3. Используйте template tags в ваших шаблонах
  4. Настройте стили под ваши потребности
