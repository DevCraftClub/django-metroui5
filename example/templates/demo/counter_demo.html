Counter Component Demo

MetroUI Counter component displays an animated numerical counter that counts up to a specified value.

Basic Usage

Simple Counter

Basic counter that counts from 0 to 100:

{% metroui5_counter value=100 %}

Counter with Custom Starting Value

Counter that starts from 50 and counts to 200:

{% metroui5_counter value=200 from_value=50 %}

Advanced Features

Counter with Prefix and Suffix

Counter with currency prefix and suffix:

{% metroui5_counter value=1000 prefix="$" suffix=" USD" %}

Counter with Custom Duration

Counter with 5-second animation duration:

{% metroui5_counter value=500 duration=5000 %}

Counter with Custom Delimiter

Counter with space as thousands separator:

{% metroui5_counter value=10000 delimiter=" " %}

Counter with Custom Size

Large counter with 32px font size:

{% metroui5_counter value=250 size=32 %}
