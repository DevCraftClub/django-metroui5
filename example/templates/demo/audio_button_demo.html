API Methods

Example of programmatic control using API methods:

Component Parameters

Parameter Type Default Description
audio_volume number 0.5 Volume level for the audio (0.0 to 1.0)
audio_src string "" Path to the audio file
on_audio_start function Metro.noop Triggered when audio starts playing
on_audio_end function Metro.noop Triggered when audio finishes playing
on_audio_button_create function Metro.noop Triggered when audio button is created

Events

Event Description
on_audio_start Triggered when audio starts playing
on_audio_end Triggered when audio finishes playing
on_audio_button_create Triggered when audio button is created

API Methods

Method Description
play(callback) Plays the audio. The callback function receives the audio element as a parameter.
stop(callback) Stops the audio and resets it to the beginning. The callback function receives the audio element as a parameter.
destroy() Destroys the audio button component.

Supported Audio Formats

The audio button component uses the HTML5 Audio API, so it supports audio formats that are compatible with the user's browser:

  • MP3 - Most widely supported format
  • WAV - Uncompressed audio format
  • OGG - Open source audio format
  • M4A - Apple's audio format
  • WebM - Web-optimized audio format

Note: For better user experience, it's recommended to use short sound files to avoid delays.

Usage Examples

Basic HTML Usage:

<!-- Simple audio button -->
<button class="button" data-role="audio-button" data-audio-src="sounds/click.mp3">
    Click Me
</button>

<!-- Audio button with custom volume -->
<button class="button success" data-role="audio-button"
        data-audio-src="sounds/success.mp3"
        data-audio-volume="0.8">
    Success
</button>

JavaScript Usage:

// Play sound on some event
$("#my-element").on("click", function(){
    Metro.playSound("sounds/notification.mp3");
});

// Play sound with options
Metro.playSound({
    audioSrc: "sounds/success.mp3",
    audioVolume: 0.7,
    onAudioStart: function(src) {
        console.log("Audio started: " + src);
    },
    onAudioEnd: function() {
        console.log("Audio ended");
    }
});

// API methods
const audioButton = Metro.getPlugin('#my-audio-button', 'audio-button');
audioButton.play(function(audio){
    console.log("Audio started playing");
});
audioButton.stop(function(audio){
    console.log("Audio stopped");
});
audioButton.destroy();
