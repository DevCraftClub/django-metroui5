MetroUI Audio Button Component

This demo showcases the MetroUI v5 Audio Button component that allows you to create buttons that play audio when clicked.

Basic Usage

Basic audio button with sound file:

{% metroui5_audio_button "Click Me" audio_src="https://cdn.bensound.com/bensound-prism.mp3" %}

Audio button with custom volume level (0.8):

{% metroui5_audio_button "Success Sound" audio_src="https://cdn.bensound.com/bensound-prism.mp3" audio_volume="0.8" class="button success" %}
