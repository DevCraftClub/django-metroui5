Component Parameters

Parameter Type Default Description
content string "" Button text content
variant string "default" Button variant (default, flat-button, outline, link)
size string "default" Button size (mini, small, medium, default, large)
shape string null Button shape (pill-button, square, cycle)
color string null Button color (primary, secondary, success, warning, alert, info)
outline boolean False Apply outline style (transparent background with colored border)
flat boolean False Apply flat style (transparent background and border)
link boolean False Apply link style (looks like a link)
shadow boolean False Apply shadow effect
shift boolean False Apply shift effect (moves when clicked)
loading boolean False Show loading state with spinner
disabled boolean False Disable the button
icon string null Icon class (e.g., 'mif-home', 'mif-plus')
icon_position string "left" Icon position ('left' or 'right')
cls_button string "" Additional CSS class for the button

Available CSS Classes

Base Classes

  • .button - Standard button
  • .flat-button - Button with flat appearance

Size Modifiers

  • .mini - Very small button (height: 20px)
  • .small - Small button (height: 26px)
  • .medium - Medium-sized button (height: 30px)
  • .large - Large button (height: 54px)

Shape Modifiers

  • .pill-button - Button with fully rounded sides
  • .square - Square button (equal width and height)
  • .cycle - Circular button

Style Modifiers

  • .outline - Button with transparent background and colored border
  • .flat - Button with transparent background and border
  • .link - Button that looks like a link
  • .shadow - Button with shadow effect
  • .shift - Button that shifts position when clicked

State Classes

  • .disabled - Visually disabled button
  • .loading - Button in loading state

Color Classes

  • .primary - Blue accent
  • .secondary - Gray accent
  • .success - Green accent
  • .warning - Yellow accent
  • .alert - Red accent
  • .info - Light blue accent

HTML Structure

<button class="button [size] [color] [shape] [effects]" type="button">
    [icon] [content]
</button>

Where:

  • [size] is one of: mini, small, medium, large
  • [color] is one of: primary, secondary, success, warning, alert, info
  • [shape] is one of: pill-button, square, cycle
  • [effects] can include: outline, shadow, shift, loading, disabled
  • [icon] is optional: <span class="icon mif-{icon-name}"></span>
  • [content] is the button text

Accessibility

  • Native button elements (<button>) are used for proper keyboard and screen reader support
  • Disabled state is properly conveyed with the disabled attribute
  • Loading state includes appropriate ARIA attributes
  • When using links as buttons, proper roles are applied

Best Practices

  • Use native <button> elements when the action will trigger functionality within the page
  • Use <a> elements styled as buttons when the action navigates to a new page
  • Always provide descriptive text for buttons to improve accessibility
  • Consider using icons alongside text for better visual recognition
  • Use color variants consistently throughout your application
