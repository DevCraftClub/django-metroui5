Activity Parameters

Parameter Type Default Description
activity_deferred number 0 Deferred initialization time in milliseconds
type string "ring" Type of activity indicator. Options: "ring", "metro", "square", "cycle", "simple", "atom", "bars"
style string "" Style of the activity indicator. Options: "", "dark", "color"
size number 64 Size of the activity indicator in pixels
radius number 20 Radius for the "simple" type activity indicator
on_activity_create string "" Callback function triggered when the activity indicator is created
cls_activity string "" Additional CSS class for the activity container

Activity Types

Type Description Visual Style
ring Default type with five rotating circles Circular rotation animation
metro Horizontal sliding animation with five circles Horizontal sliding motion
square Square animation with four squares that drop into place Square dropping animation
cycle Circular spinning animation with concentric circles Concentric circle rotation
simple Circular path animation Simple circular motion
atom Three rotating elliptical orbits Atomic orbital motion
bars Six vertical bars that animate up and down Vertical bar animation

Style Options

Style Description Color Scheme
default Uses the --activity-color variable (dark in light mode, light in dark mode) Theme-adaptive
dark Forces dark styling regardless of the current theme Dark colors
color Uses predefined colors (cyan, orange, green, red, yellow, etc.) for multi-colored animation Multi-colored
