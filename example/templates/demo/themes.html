Настройка тем

Для настройки тем используйте следующие параметры в settings.py:

METROUI5 = {
    # Тема: 'light', 'dark', или 'auto'
    'theme': 'light',
    
    # Target элемент для применения темы
    'theme_target': 'html',
    
    # Включить theme switcher
    'theme_switcher_enabled': True,
}

Доступные значения темы:

  • light - светлая тема (по умолчанию)
  • dark - темная тема
  • auto - автоматическое определение по системным настройкам

Target элементы:

  • html - применять тему к тегу <html> (по умолчанию)
  • body - применять тему к тегу <body>
  • CSS селектор - например #app, .container
