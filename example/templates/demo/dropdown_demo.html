Best Practices

  • ✓ Use clear and descriptive labels for dropdown toggles
  • ✓ Keep dropdown menus concise and organized
  • ✓ Consider using icons alongside text for better visual recognition
  • ✓ Use appropriate positioning based on the location of the dropdown in the UI
  • ✓ Ensure dropdown content is accessible and navigable via keyboard
  • ✓ Test dropdown behavior on different screen sizes
  • ✓ Use keep-open sparingly to avoid confusing users

Component API

Parameter Type Default Description

button_textstring""Text for the button toggle
toggle_elementstringNoneCustom toggle element HTML
itemslistNoneAuto-generate menu from items
open_modestring"auto"Positioning: "auto", "up", "left", "right"
heightstring"auto"Fixed height with scrolling
dropdown_deferrednumber0Delay before initialization (ms)
keep_openbooleanfalseStay open when clicking elsewhere (CSS class)

on_upstringNoneJavaScript event when dropdown closes
