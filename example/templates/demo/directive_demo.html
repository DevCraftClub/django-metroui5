Component Parameters

Parameter Type Default Description
content string "" Directive content text
directive string "note" Type of directive. Options: "note", "info", "warning", "caution", "tip", "success", "important", "bug", "shit", "air", "fuck"
show_icon boolean true Whether to show an icon
title string "default" Title of the directive. If set to "default", it will use the localized label for the directive type
style number 1 Style of the directive. Options: 1, 2, 3
on_directive_create string "" Event fired when directive is created
cls_directive string "" Additional CSS class for directive element
cls_title string "" Additional CSS class for title element
cls_content string "" Additional CSS class for content element
