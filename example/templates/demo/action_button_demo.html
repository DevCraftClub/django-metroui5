Action Button Parameters

Parameter Type Default Description
actions list - List of action dictionaries with 'icon', 'href', 'title', 'onclick'
main_icon string "mif-plus" Icon class for the main action button
rotate boolean false Add rotation effect to main button
main_href string "" URL for main button
main_title string "" Title/tooltip for main button
main_onclick string "" JavaScript onclick handler for main button
onClick string "" Callback function triggered when main button is clicked
onActionClick string "" Callback function triggered when sub-action is clicked
onActionButtonCreate string "" Callback function triggered when action button is created

Action Item Structure

Key Type Required Description
icon string Yes Icon class for the action (e.g., 'mif-home')
href string No URL for the action link
title string No Title/tooltip for the action
onclick string No JavaScript onclick handler for the action
