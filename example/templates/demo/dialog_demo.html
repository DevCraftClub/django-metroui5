Component Parameters

Parameter Type Default Description
title string "" Dialog title text
content string "" Dialog content text
close_button boolean false Show close button in top-right corner
custom_buttons array [] Array of custom button objects
actions_align string "right" Alignment of action buttons: "left", "center", "right"
default_actions boolean true Show default action buttons
default_action_buttons string "ok,cancel,help" Comma-separated list of default buttons
overlay boolean true Show overlay behind dialog
overlay_color string "#000000" Color of the overlay
overlay_alpha number 0.5 Opacity of the overlay (0.0 to 1.0)
overlay_click_close boolean false Close dialog when clicking on overlay
width string "auto" Width of the dialog
height string "auto" Height of the dialog
auto_hide number 0 Auto hide dialog after specified milliseconds (0 = disabled)
remove_on_close boolean false Remove dialog element from DOM when closed
show boolean false Show dialog immediately after initialization
to_top boolean false Position dialog at top of screen
to_bottom boolean false Position dialog at bottom of screen

Event Handlers

Event Description
on_show Triggered when dialog is shown
on_hide Triggered when dialog is hidden
on_open Triggered when dialog is opened
on_close Triggered when dialog is closed
on_ok Triggered when OK button is clicked
on_cancel Triggered when Cancel button is clicked
on_help Triggered when Help button is clicked
on_dialog_create Triggered when dialog is created

API Methods

Method Description
Metro.dialog.create(options) Create a dialog dynamically
Metro.getPlugin(element, 'dialog').open() Open an existing dialog
Metro.getPlugin(element, 'dialog').close() Close an existing dialog
Metro.getPlugin(element, 'dialog').destroy() Destroy the dialog instance
