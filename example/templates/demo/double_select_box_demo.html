Component Parameters

Parameter Type Default Description
left_options list [] List of options for the left select box
right_options list [] List of options for the right select box
height string "auto" Height of the select boxes
multi_select boolean false Allows selecting multiple items at once
move_right_icon string "›" Icon for the move right button
move_right_all_icon string "»" Icon for the move all right button
move_left_icon string "‹" Icon for the move left button
move_left_all_icon string "«" Icon for the move all left button
cls_box string "" Additional CSS class for the component container
cls_move_button string "" Additional CSS class for all move buttons
cls_list_left string "" Additional CSS class for the left list
cls_list_right string "" Additional CSS class for the right list
on_double_select_box_create string "" Triggered when the component is created

Option Format

Property Type Required Description
value string Yes The value attribute of the option
text string Yes The display text of the option
template string No HTML template for custom option display (use $1 for text placeholder)

Interaction Methods

Method Description
Double-click item Move single item to the other list
Select + Move button Move selected item(s) to the other list
Move All button Move all items from one list to the other
Multi-select mode Hold Ctrl/Cmd to select multiple items at once

CSS Variables

Variable Default (Light) Dark Mode Description
--double-select-border-radius 4px 4px Border radius of the select boxes
--double-select-border-color var(—border-color) var(—border-color) Border color of the select boxes
--double-select-item-background-active #e6e6e6 #2c2d30 Background color of active items
--double-select-item-color-active #191919 #efefef Text color of active items
--double-select-item-background-hover #e6e6e6 #2c2d30 Background color of items on hover
--double-select-item-color-hover #191919 #efefef Text color of items on hover
