Usage Examples

Basic Usage

With Custom Size

{% templatetag openblock %} avatar_initials "Jane Smith" size="large" {% templatetag closeblock %}

With Custom Colors

{% templatetag openblock %} avatar_initials "Bob Wilson" bg_color="#e74c3c" text_color="white" {% templatetag closeblock %}

Different Shapes

{% templatetag openblock %} avatar_initials "Alice Brown" shape="rounded" {% templatetag closeblock %}

Multiple Initials

{% templatetag openblock %} avatar_initials "John Michael Smith" max_initials=3 {% templatetag closeblock %}

Features

  • No External Dependencies: Uses pure HTML/CSS, no Cairo or other graphics libraries required
  • Consistent Colors: Automatically generates consistent background colors from names
  • Flexible Sizing: Supports small, medium, large, and xlarge sizes
  • Multiple Shapes: Circle, square, and rounded rectangle options
  • Smart Initials: Automatically extracts initials from full names
  • Accessible: Includes proper ARIA labels and titles
  • Responsive: Works well on all screen sizes
