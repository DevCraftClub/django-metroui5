Component Parameters

Parameter Type Default Description
items list [] List of menu items (strings or dicts)
button_text string "Menu" Text for the toggle button
height string/number "auto" Maximum height of the menu. Can be "auto" or a specific pixel value
align string "left" Horizontal alignment of the menu. Can be "left" or "right"
keep_open boolean false Prevents the menu from closing when clicking elsewhere
stay_open boolean false Alternative to keep_open
ignore_document_click boolean false Another alternative to keep_open
button_class string "" Additional CSS classes for the button
on_menu_create string "" Callback function that fires when the menu is created

Item Format

Type Example Description
String "Menu Item" Simple text item with default link
Dictionary {'text': 'Item', 'href': '/link/'} Item with custom link
With Submenu {'text': 'More', 'submenu': [...]} Item with nested submenu
With CSS Class {'text': 'Item', 'class': 'custom-class'} Item with custom CSS class

API Methods

Method Description Example
open() Opens the drop menu dropMenu.open()
close() Closes the drop menu dropMenu.close()
destroy() Removes the drop menu component dropMenu.destroy()

CSS Classes

Class Description
.drop-menu The main container for the drop menu
.menu-toggle The toggle button/element that triggers the menu
.active-toggle Applied to the toggle when the menu is open
.keep-open Prevents the menu from closing when clicking elsewhere
.stay-open Alternative class that prevents the menu from closing
.ignore-document-click Another alternative class with the same functionality

Special Features

Key Features of Drop Menu

  • Auto-Positioning: Automatically adjusts position to stay within viewport
  • Nested Menus: Supports unlimited nesting of submenus
  • Keep-Open Feature: Option to prevent menu from closing when clicking elsewhere
  • Static Positioning: Unlike dropdown component, uses static positioning
  • Responsive Design: Automatically adapts to different screen sizes
  • Touch-Friendly: Optimized for touch interactions on mobile devices

Best Practices

Tips for Using Drop Menu Components

  • Use semantic HTML for menu structures (typically <ul> and <li> elements)
  • Keep menu items concise and organized logically
  • Consider using icons alongside text for better visual recognition
  • Limit the depth of nested menus to improve usability
  • Ensure menu items have sufficient spacing for touch interactions
  • Use the auto-positioning feature rather than manually positioning menus
  • Test menu behavior on different screen sizes and devices
