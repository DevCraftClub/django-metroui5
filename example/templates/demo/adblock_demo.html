MetroUI Adblock Detection Component

This demo showcases the MetroUI v5 Adblock Detection component that can detect if users have ad blockers enabled.

JavaScript Event Handlers

Example JavaScript functions to handle adblock detection events:

// Listen for adblock detection events
$(window).on("adblock-alert", function() {
    console.log("Ad blocker detected!");
    // Show alternative content or message
    showAdblockMessage();
});

$(window).on("fishing-start", function() {
    console.log("Adblock detection started");
});

$(window).on("fishing-done", function() {
    console.log("Adblock detection completed");
});

// Example callback functions
function handleAdblock() {
    alert("Ad blocker detected! Please disable it to see ads.");
}

function showAdblockMessage() {
    // Show a custom message or alternative content
    document.getElementById('adblock-message').style.display = 'block';
}

function startDetection() {
    console.log("Starting adblock detection...");
}

function stopDetection() {
    console.log("Adblock detection finished.");
}

Global Configuration

You can also configure adblock detection globally:

// Configure adblock detection globally
Metro.adblockSetup({
    checkInterval: 2000,
    fireOnce: true,
    localhost: false,
    onAlert: function() {
        console.log("Ad blocker detected!");
    }
});

API Methods

The Adblock component provides these API methods:

// Manually start the adblock detection
Metro.Adblock.bite();

// Start checking for ad blockers
Metro.Adblock.fishing();

Component Parameters

Parameter Type Default Description
adblock_deferred number 0 Deferred initialization time in milliseconds
check_interval number 1000 Interval in milliseconds to check for ad blockers
fire_once boolean/number true Whether to fire the alert event only once
check_stop number 10 Number of checks before stopping
localhost boolean false Whether to check for ad blockers on localhost
on_alert function Metro.noop Callback when ad blocker is detected
on_fishing_start function Metro.noop Callback when detection starts
on_fishing_done function Metro.noop Callback when detection is done
