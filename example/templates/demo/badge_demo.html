MetroUI Badge Component

This demo showcases the MetroUI v5 Badge component that provides a simple way to add small, customizable badges to your UI elements.

Basic Usage

Basic badge with default styling:

{% metroui5_badge "New" %} {% metroui5_badge "5" %} {% metroui5_badge "Alert" %} {% metroui5_badge "Status" %}

Component Parameters

Parameter Type Default Description
content string "" Badge content/text
corner boolean false Position the badge in the top-right corner of a relative-positioned parent
corner_outside boolean false Position the badge outside the parent element in the top-right corner
cls_badge string "" Additional CSS class for the badge

CSS Variables

Variable Default (Light) Dark Mode Description
--badge-background #F8F8F8 #2b2d30 Background color of the badge
--badge-color #191919 #F8F8F8 Text color of the badge
--badge-border-radius 4px 4px Border radius of the badge

Available CSS Classes

Base Classes

  • .badge - The main class for creating a badge

Modifiers

  • .corner - Positions the badge in the top-right corner of a relative-positioned parent
  • .corner-outside - Positions the badge outside the parent element in the top-right corner

Python Usage:

from metroui5.components import render_badge

# Basic badge
html = render_badge("New")

# Corner badge
html = render_badge("8", corner=True)

# Outside corner badge
html = render_badge("12", corner_outside=True)

# Custom styled badge
html = render_badge("Custom", cls_badge="custom-badge")

Custom Styling:

/* Custom styling for badges */
.custom-badge {
    --badge-background: #2196F3;
    --badge-color: white;
    --badge-border-radius: 12px;
}

/* Notification badge */
.notification-badge {
    --badge-background: #F44336;
    --badge-color: white;
    --badge-border-radius: 50%;
    font-size: 10px;
    min-width: 18px;
    height: 18px;
    line-height: 18px;
}

Additional Information

The Badges component:

  • Is purely CSS-based with no JavaScript functionality
  • Automatically adapts to both light and dark themes
  • Uses flexbox for proper text alignment and centering
  • Has a default small font size (10px) and padding for compact display
  • Can be positioned relative to parent elements using the corner classes
  • Supports custom styling through CSS variables
  • Is perfect for notification counts, status indicators, and labels
