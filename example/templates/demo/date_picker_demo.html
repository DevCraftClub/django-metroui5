Python Usage:

from metroui5.components import render_date_picker

# Basic usage
render_date_picker()

# With label and value
render_date_picker(label="Select date:", value="2024-01-15")

# With custom format and locale
render_date_picker(format="DD/MM/YYYY", locale="uk-UA")

# With year range and validation
render_date_picker(min_year=2020, max_year=2030, error=True, error_message="Invalid date")

Additional Information

The Date Picker component:

  • Uses a wheel-based interface for intuitive date selection
  • Supports various date formats and locales
  • Allows customization of which date parts to show (month, day, year)
  • Supports year range restrictions
  • Can be configured to open in different modes (auto, dialog, up)
  • Integrates with the Metro UI theming system
  • Provides extensive customization options for styling and behavior
  • Includes comprehensive event handling for user interactions
  • Supports validation states and error messaging
