MetroUI Bar3d Component

This demo showcases the MetroUI v5 Bar3d component that creates a 3D bar chart visualization. It displays a value as a growing bar in a 3D perspective, with customizable colors and animations.

Component Parameters

Parameter Type Default Description
height number 200 The height of the bar
bar_color string "#22ec1a" The color of the growing bar
value_color string "#191919" The color of the displayed value text
total number 100 The total value (maximum)
value number 60 The current value to display
value_suffix string "" A suffix to append to the displayed value (e.g., "%")
animation_duration number 300 The duration of the animation in milliseconds
on_bar3d_create function Metro.noop Callback function triggered when the component is created
cls_bar3d string "" Additional CSS class for the bar3d container

CSS Variables

Variable Default (Light) Dark Mode Description
--chart-height 160px - The height of the chart
--bar-height 160px - The height of the bar
--bar-width 32px - The width of the bar
--bar-value-color #191919 - The color of the displayed value text
--bar-bottom-color rgba(194, 157, 11, 0.2) - The color of the bottom side of the bar
--bar-top-color rgba(254, 254, 254, 0.8) - The color of the top side of the bar
--bar-left-color rgba(241, 241, 241, 0.8) - The color of the left side of the bar
--bar-right-color rgba(216, 216, 216, 0.8) - The color of the right side of the bar

Available CSS Classes

Base Classes

  • .bar3d - The main container class for the component
  • .side - Applied to all sides of the 3D bar
  • .left-side - The left side of the 3D bar
  • .right-side - The right side of the 3D bar
  • .top-side - The top side of the 3D bar
  • .bottom-side - The bottom side of the 3D bar
  • .growing-bar - The animated bar that grows to represent the value

API Methods

Method Description
changeAttribute(attr, newValue) Changes a component attribute. Currently supports changing the data-value attribute.
destroy() Removes the component from the DOM.

Usage Examples

Basic HTML Usage:

<!-- Basic usage -->
<div data-role="bar3d"></div>

<!-- With custom value and color -->
<div data-role="bar3d"
     data-value="30"
     data-bar-color="#00d153"
     data-value-suffix="%"
     data-value-color="#fff">
</div>

Python Usage:

from metroui5.components import render_bar3d

# Basic bar3d
html = render_bar3d()

# With custom parameters
html = render_bar3d(value=75, bar_color="#00d153", value_suffix="%")

# With height and animation
html = render_bar3d(height=250, value=60, animation_duration=500)

JavaScript Initialization:

// Initialize with Metro.makePlugin
const bar3d = Metro.makePlugin("#myBar", "bar3d", {
    value: 60,
    barColor: "#22ec1a",
    valueSuffix: "%"
});

// Or globally configure defaults
Metro.bar3dSetup({
    barColor: "#22ec1a",
    animationDuration: 500
});

// Change value dynamically
const bar3d = Metro.getPlugin('#myBar', 'bar3d');
bar3d.changeAttribute('data-value', 75);

Custom Styling:

Additional Information

The Bar3d component:

  • Creates a 3D bar chart visualization using CSS 3D transformations
  • Displays a value as a growing bar in a 3D perspective
  • Supports customizable colors and animations
  • The value is displayed on the growing bar using the ::before pseudo-element
  • Automatically updates when the data-value attribute is changed
  • Perfect for progress indicators, statistics, and data visualization
  • Uses CSS 3D transformations for the 3D effect
  • Supports dynamic value updates through JavaScript API
