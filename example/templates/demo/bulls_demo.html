Component Parameters

Parameter Type Default Description
bull_type string "success" Type of bull icon. Possible values: "success", "fail", "pending", "warning", "bulb-on", "bulb-off", "star", "badge", "chat", "tree", "checkmark", "cancel", "rocket", "default"
size number 16 Size of the bull icon in pixels
onBullCreate function Metro.noop Callback function triggered when the bull is created
onBullChange function Metro.noop Callback function triggered when the bull type is changed
cls_bull string "" Additional CSS class for the bull container
cls string "" General additional CSS classes

Bull Types Reference

Type Description Default Color Use Case
success Indicates a successful operation Green (#57ab5a) Completed tasks, successful submissions
fail Indicates a failed operation Red (#e5534b) Errors, failed operations
pending Indicates an operation that is still in progress (animated) Yellow (#DBAB0A) Loading states, pending operations
warning Indicates a warning or caution Orange (#ff4d00) Warnings, attention needed
bulb-on Represents an active informational state Yellow (#ffde21) Active notifications, enabled features
bulb-off Represents an inactive informational state Gray Inactive notifications, disabled features
star Represents a star icon Yellow Favorites, highlights, ratings
badge Represents a badge icon Blue Notifications, counts, achievements
chat Represents a chat icon Blue Messaging, communication
tree Represents a tree icon Green Hierarchical data, navigation
checkmark Represents a checkmark icon Green Confirmations, selections
cancel Represents a cancel icon Red Dismissing, closing actions
rocket Represents a rocket icon Blue Launching, starting actions
default Default bull type Gray Generic status indicator

API Methods

Method Description Example
setType(type) Changes the type of the bull component bull.setType('warning')
changeAttribute(attr, value) Changes the attribute of the bull component bull.changeAttribute('size', 32)
destroy() Removes the bull element from the DOM bull.destroy()

Events

Event Description
bull-create Triggered when the bull component is created
bull-change Triggered when the bull type is changed

Global Configuration

You can set up global configuration for all bull components using:

Metro.bullSetup({
    size: 32
});

HTML Structure

<div data-role="bull" data-type="success" data-size="24"></div>

Where:

  • data-role="bull" - Identifies the element as a bull component
  • data-type - Specifies the type of bull icon
  • data-size - Sets the size of the bull icon in pixels
  • data-on-bull-create - Optional callback for creation event
  • data-on-bull-change - Optional callback for change event

Additional Information

  • Bulls component displays different types of status indicators as SVG icons
  • Useful for showing success, failure, pending, warning, or informational states
  • Uses SVG with inline styling, so there are no specific CSS variables to customize
  • Colors are defined within the SVG paths
  • Supports custom colors via inline styles or CSS classes
  • Provides JavaScript API for dynamic type changes
  • Supports event callbacks for creation and change events
  • Can be globally configured for consistent sizing across the application
