Component Parameters

Parameter Type Default Description
front_content string/HTML "" Content for the front side of the card
back_content string/HTML "" Content for the back side of the card
flip_horizontal boolean false Make the card flip horizontally instead of vertically
effect_on_hover boolean false Trigger flip effect on hover
effect_on_active boolean false Trigger flip effect when card has active class
width string "" Width of the flip card (e.g., "300px", "100%")
height string "" Height of the flip card (e.g., "200px", "100%")
animation_speed string "" Duration of the flip animation (e.g., "0.3s", "0.5s")
perspective string "" Perspective value for 3D effect (e.g., "600px", "1000px")
cls_flip_card string "" Additional CSS class for flip card container
cls_front string "" Additional CSS class for front side
cls_back string "" Additional CSS class for back side

CSS Classes

Class Description
.flip-card The main container class for the flip card component
.front The front side of the card
.back The back side of the card
.flip-horizontal Makes the card flip horizontally (by default, the card flips vertically)
.effect-on-hover Triggers the flip effect when the user hovers over the card
.effect-on-active Triggers the flip effect when the card has the active class

CSS Variables

Variable Default Description
--defaultAnimationSpeed 0.3s The duration of the flip animation
--defaultPerspective 600px The perspective value for the 3D effect
