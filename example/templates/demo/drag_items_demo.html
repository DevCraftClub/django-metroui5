Component Parameters

Parameter Type Default Description
items list [] List of items to render (strings or dicts)
drag_items_deferred number 0 Delay in milliseconds before initialization
target string/object null Target element for dropping items
drag_item string "li" Selector for draggable items
drag_marker string ".drag-item-marker" Selector for drag marker
draw_drag_marker boolean false Whether to draw drag markers
can_drag boolean true Whether dragging is enabled
cls_drag_item_avatar string "" Additional CSS class for drag avatar
cls_drag_item string "" Additional CSS class for drag item

Event Handlers

Event Description
on_drag_start_item Triggered when dragging starts
on_drag_move_item Triggered when dragging moves
on_drag_drop_item Triggered when item is dropped
on_target Triggered when over a target
on_target_in Triggered when entering a target
on_target_out Triggered when leaving a target
on_drag_items_create Triggered when component is created

API Methods

Method Description Example
on() Enables dragging functionality dragItems.on()
off() Disables dragging functionality dragItems.off()
toggle() Toggles dragging functionality on/off dragItems.toggle()
destroy() Removes event handlers and cleans up the component dragItems.destroy()

Item Format

Type Example Description
String "Item Text" Simple text content for the item
Dictionary {'content': 'Item Text', 'class': 'custom-class'} Item with content and optional attributes
Dictionary with ID {'content': 'Item Text', 'id': 'item-1'} Item with specific ID for targeting
Complex Dictionary {'content': 'HTML content', 'class': 'priority-high', 'data-priority': '1'} Item with custom attributes and data

CSS Classes

Class Description
.drag-items-target Applied to the container element
.dragged-item Applied to the item being dragged (opacity: 0.3)
.drag-item-marker Styling for the drag marker (hamburger icon)
.dragged-item-avatar Styling for the avatar element that follows the cursor during dragging
.drag-marker-dark Dark theme variant for the drag marker
