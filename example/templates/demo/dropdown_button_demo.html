Component Parameters

Parameter Type Default Description
button_text string "Options" Text displayed on the button
items list None List of menu items (strings or dicts)
content string "" Custom HTML content for dropdown
button_style string "" Button style (primary, success, warning, etc.)
button_size string "" Button size (large, small, mini)
outline boolean false Use outline button style
flat boolean false Use flat button style
rounded boolean false Use rounded button corners
icon string "" Icon class for button
icon_position string "left" Icon position (left, right)
drop_up boolean false Position dropdown above button
drop_right boolean false Position dropdown to the right
no_close boolean false Prevent closing when clicking outside
duration number 50 Animation duration in milliseconds
height string "auto" Fixed height for dropdown
