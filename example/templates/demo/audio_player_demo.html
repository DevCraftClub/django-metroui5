Component Parameters

Parameter Type Default Description
src string "" Path to the audio file
show_loop boolean true Show or hide loop control
show_play boolean true Show or hide play control
show_stop boolean true Show or hide stop control
show_stream boolean true Show or hide stream control
show_volume boolean true Show or hide volume control
show_info boolean true Show or hide info display
loop boolean false Enable looping audio
autoplay boolean false Start playback automatically
volume number 1.0 Initial volume (0.0 to 1.0)

Custom Icons Parameters

Parameter Type Description
loop_icon string Custom icon for loop control
play_icon string Custom icon for play control
pause_icon string Custom icon for pause control
stop_icon string Custom icon for stop control
mute_icon string Custom icon for mute control
volume_low_icon string Custom icon for low volume
volume_medium_icon string Custom icon for medium volume
volume_high_icon string Custom icon for high volume

Events

Event Description
on_play Triggered when playback starts
on_pause Triggered when playback is paused
on_stop Triggered when playback stops
on_end Triggered when playback ends
on_metadata Triggered when metadata is loaded
on_time Triggered during playback to update current time
on_audio_create Triggered when audio player is created

API Methods

Method Description
play() Start playback
play(src) Start playback of a specific audio source
pause() Pause playback
resume() Resume playback
stop() Stop playback
volume() Get the current volume
volume(vol) Set the volume
loop() Toggle looping
mute() Mute the audio

Supported Audio Formats

The audio player component uses the HTML5 Audio API and supports:

  • MP3 - Most widely supported format
  • WAV - Uncompressed audio format
  • OGG - Open source audio format
  • M4A - Apple's audio format
  • WebM - Web-optimized audio format
  • AAC - Advanced Audio Coding format

JavaScript Usage:

// Access the audio player
var player = Metro.getPlugin('audio', 'audio-player');

// Control playback
player.play();
player.pause();
player.resume();
player.stop();

// Control volume
player.volume(0.5);  // Set volume to 50%
var currentVolume = player.volume();  // Get current volume

// Toggle features
player.loop();  // Toggle looping
player.mute();  // Mute/unmute

// Event handling
$('#my-audio-player').on('play', function() {
    console.log('Audio started playing');
});

$('#my-audio-player').on('pause', function() {
    console.log('Audio paused');
});

$('#my-audio-player').on('end', function() {
    console.log('Audio finished playing');
});
