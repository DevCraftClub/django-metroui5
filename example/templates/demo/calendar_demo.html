Component Parameters

Parameter Type Default Description
show string/object null Date to show in calendar
week_start int null First day of week (0 for Sunday, 1 for Monday, etc.)
static boolean false If true, calendar becomes non-interactive
readonly boolean false If true, calendar is read-only
show_ghost boolean false If true, shows ghost days from previous/next months
events string/list null Array or comma-separated string of dates with events
show_time boolean false If true, enables time selection
initial_time string null Initial time in "HH:MM" format
compact boolean false If true, shows compact calendar
wide boolean false If true, shows wide calendar
picker_mode boolean false If true, enables picker mode for date selection
day_border boolean false If true, shows day borders
ripple boolean false If true, enables ripple effect
ripple_color string "#cccccc" Color for ripple effect
exclude string/list null Array or comma-separated string of dates to exclude
preset string/list null Array or comma-separated string of preset selected dates
min_date string null Minimum selectable date
max_date string null Maximum selectable date
week_day_click boolean false If true, enables clicking on week days
week_number_click boolean false If true, enables clicking on week numbers
multi_select boolean false If true, enables multiple date selection
special string/list null Array or comma-separated string of special dates
format string METRO_DATE_FORMAT Format for date output
input_format string null Format for date input

Available CSS Classes

Base Classes

  • .calendar - Main calendar container
  • .compact - Compact calendar
  • .day-border - Calendar with day borders

Component Classes

  • .calendar-header - Calendar header
  • .calendar-content - Calendar content area
  • .calendar-footer - Calendar footer
  • .calendar-time - Time selection area

State Classes

  • .selected - Selected date
  • .excluded - Excluded date
  • .today - Today's date
  • .special - Special date
  • .outside - Date outside current month
  • .weekend - Weekend date

HTML Structure

<div class="calendar [modifiers]" data-role="calendar" [data-attributes]></div>

Where:

  • [modifiers] can include: compact, wide, day-border
  • [data-attributes] include all the configuration options as data attributes
  • The calendar content is generated dynamically by MetroUI JavaScript

Accessibility

  • Proper ARIA roles and attributes for interactive elements
  • Keyboard navigation support
  • Screen reader friendly structure
  • High contrast support through CSS variables

Best Practices

  • Use appropriate date formats for your target audience
  • Provide clear visual indication of selected dates
  • Use the minDate and maxDate options to limit date selection when appropriate
  • Consider using the exclude option for dates that should not be selectable
  • Implement appropriate event handlers to respond to user interactions
  • Use CSS variables for consistent styling across your application
